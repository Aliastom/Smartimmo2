## 💼 COMPÉTENCE D - DÉTAILS

### 8 Types d'Analyses

1. ✅ **Cashflow** - Flux de trésorerie mensuel/annuel
2. ✅ **Rendement** - Brut, net, net-net fiscal
3. ✅ **Fiscalité** - LMNP vs Foncier, optimisation
4. ✅ **Projection** - Simulations futures
5. ✅ **IRL** - Indexation des loyers
6. ✅ **TRI** - Taux de Rendement Interne
7. ✅ **Amortissement** - Calcul LMNP
8. ✅ **Optimisation** - Conseils fiscaux

### Formules Implémentées

**Cashflow :**
```
= Loyers - Charges - Prêt - Impôts
```

**Rendement brut :**
```
= (Loyer annuel / Coût total) × 100
```

**Rendement net :**
```
= ((Loyer - Charges - Taxe foncière) / Coût) × 100
```

**Fiscalité LMNP :**
```
Amortissement = (Prix × 0.85) / 25 ans
Revenu imposable = Loyers - Charges - Intérêts - Amortissement
Impôt = (Revenu × Taux IR) + (Revenu × 17,2%)
```

**Indexation IRL :**
```
Loyer nouveau = Loyer actuel × (1 + Taux / 100)
```
